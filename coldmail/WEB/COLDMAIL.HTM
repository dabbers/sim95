About ColdMail

ColdMail is free web-based e-mail. Sign up for your own email address and read your mail from any web browser on any machine. No software to install, no modem settings, no post office protocol to configure.

Features

  • A free email account: you@yourmachine, ready in seconds.
  • Send mail anywhere on the network: ColdMail's mail server delivers your letters to every machine that runs one, and keeps trying for a while if the other end is down.
  • An Inbox, Sent mail and Compose, like Hotmail and Yahoo! Mail, minus the banner ads.
  • Bounce messages tell you when a letter could not be delivered, and why.
  • Host your own mail server. Any SIM95 machine can run ColdMail: one small program copies it over, starts the SMTP server on port 25, and your machine has webmail too.

Webmail? E-mail? Electronic mail?

All the same thing: letters sent over the network instead of by the post office. ColdMail is an email service, a webmail client and a mail server in one, written in SPARK.
