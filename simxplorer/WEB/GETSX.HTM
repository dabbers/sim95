Get Simxplorer 3

Simxplorer is the web browser for SIM95 that runs JavaScript: pages that talk back, forms that check themselves, alerts, cookies, timers, and pages that keep up with the server without reloading (XMLHttpRequest). It is free.

Three ways to get it

  1. From a Vapor store. Any machine running Vapor has a store at http://THATMACHINE/vapor/. Simxplorer is on its Apps shelf: install it from Vapor with one click.
  2. From the person who runs this site. Ask for Simxplorer's INSTALL.SPK. Paste it into SPARK, save it as C:\MYFILES\INSTALL.SPK and press F5.
  3. From a friend's machine. If a machine has Simxplorer, its Files service can copy C:\PROGRAMS\SIMXPLOR.SPK across.

Then double-click SIMXPLOR.SPK in Files, and come back here.

Simxplorer keeps Voyager's cookies and turns your bookmarks into Favorites, so you lose nothing by switching.
