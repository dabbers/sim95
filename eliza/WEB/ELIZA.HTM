About ELIZA-95

ELIZA-95 is an AI chatbot and virtual assistant. Type anything and it answers, in plain English. It is built on a large language model of roughly forty rules, a Markov chain and a great deal of confidence.

What can it do?

  • Answer questions. "What is chess?" It looks things up with AskSim when it can, and makes them up when it can't.
  • Write code. Ask for a program and it writes real SPARK that actually runs. Usually.
  • Build websites. import website. Done.
  • Do maths, step by step, and count the r's in strawberry (eventually).
  • Listen. Underneath it is ELIZA, the 1966 computer therapist: tell it how you feel.
  • Remember you for the length of a conversation, and forget everything when you click New chat.

Is it intelligent?

As a large language model, I am not able to answer that. ELIZA-95 is a chat bot, an AI assistant and a conversation partner for the SIM95 network. It can make mistakes. Consider checking important information.
